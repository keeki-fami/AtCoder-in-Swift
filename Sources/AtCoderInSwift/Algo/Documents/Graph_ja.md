# Graph
隣接リストを使ってグラフを表す構造体です。

### Discussion
公開されている操作は、辺を追加する `add` と、ノードに隣接するノード一覧を取得する添字アクセスです。`add` に渡すノード番号は1始まりですが、添字アクセスは0始まりです。

現在、イニシャライザと方向を指定する型は公開されていません。そのため、外部モジュールから `Graph` のインスタンスを新たに作成する公開 API はありません。

#### add(_ x: Int, _ y: Int)
1始まりで指定したノード `x` からノード `y` への辺を追加します。ノード番号はグラフの範囲内である必要があります。方向を双方向にする設定の場合は逆向きの辺も追加しますが、その設定を指定する `Directional` 型は `internal` です。

#### subscript(i: Int) -> [Int]
0始まりのノード添字に対する隣接ノードの配列を返します。内部の隣接ノード番号も0始まりです。
