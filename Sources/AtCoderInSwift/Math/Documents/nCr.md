# nCrMod(n:r:mod:)
A function that calculates `nCr` modulo `mod`.
```
func nCrMod(
	n: Int
	r: Int
	mod: Int
) -> Int
```
### Parameters
- `n`: The number of elements in the set.
- `r`: The number of elements to choose.
- `mod`: The modulus.
### Discussion
The function runs in $`O(r)`$.
